Музика для інтро

Як це працює
  1. Угорі оберіть варіант музики.
  2. ▶ Прослухати — звук разом з анімацією інтро.
  3. Змініть інструмент чи гучність — зміна зазвучить одразу. «🎧 окремо» — послухати один інструмент. Ноти тягніть мишею в сітці праворуч.
  4. Сподобалось — «Поставити в інтро»: нові відео будуть з цією музикою. Доти інтро не змінюється.
Це музика, яка зараз в інтро. Щоб змінити — натисніть «Копія» і правте копію, потім «Поставити в інтро».

Нота

Сітка
Сила удару
Клік по сітці — нова нота (потягніть, щоб задати довжину). Тягніть ноту, щоб посунути; за правий край — щоб змінити довжину. Подвійний клік або Delete — видалити. Клік по клавішах ліворуч — почути висоту. Пробіл — прослухати. Кольорові лінії вгорі — моменти анімації.
